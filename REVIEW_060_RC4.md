# GharTV 0.6.0 RC4

One existing product, one review APK, one loopback browser service on8790.

- Source checkout is preserved regardless of non-main/dirty state. Release bytes are checked independently.
- Dates: Jio account → Appearance → Edit family dates. These are local overrides, not telemetry.
- Picture: per-channel shape plus live source stats and adaptive/highest/data-saver session preference.
- Diagnostics: optional extra hardware sharing is a distinct consent. Owner UI/log time zone is IST.
- Messages: pair from the TV, then confirm a selected/all-listed-TV broadcast in the owner HTML. A queued message is not a delivered/read message.
- Web: same existing JioTV frontend and provider authentication path; a successful local health check is not proof of provider playback.
- Downloads: historical published APK names with explicit review/old-release warnings; no forced downgrades.
- AI super-resolution is not running. Source quality selection and picture resizing must not be sold as native4K reconstruction.

Public production remains the independently approved RC8/code17. No public code20 promotion until owner acceptance.
