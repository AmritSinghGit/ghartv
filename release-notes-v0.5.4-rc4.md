# GharTV Jio Live v0.5.4 RC4 — Family Preview

Owner-review prerelease continuing the same `ghartv` product and signing identity.

## Living-room interface
- Restores the long vertical selected-channel tile requested after RC3.
- Adds an explicit, muted, 15-second channel preview inside the tile; it never autoplays on focus and releases its decoder automatically.
- Keeps Watch Live fully visible, with Favourite and a true previous-channel Recall below it.
- Refines text alignment, translucent surfaces and spacing for a 65-inch television.
- Removes internal RC/version labels from the normal home screen.

## Family tribute
- Correct mappings for Dad, Simrat, Mom, Amrit, Harjas, Wifey and Sis.
- Automatic date mode plus separate birthday and standard previews.
- Richer static birthday glass theme without an animation loop.

## Search and playback
- Voice channel/programme search with typed fallback.
- Indexed channel search plus bounded Jio EPG programme search.
- Smaller, more translucent Now/Next player panel.
- Visible Pause, rewind 15s, forward 15s and Live controls only when the stream exposes the required capability.
- Existing scoped CH±, automatic recovery, subscription/access separation and telemetry remain.

## Analytics boundary
GharTV stays an independent product. Tenant `ghartv` remains assigned to the existing `operon.analytics` lane and PR #61. Missing local analytics materialisation no longer blocks the Android TV candidate. Stable televisions remain on v0.5.3 until explicit owner approval.
