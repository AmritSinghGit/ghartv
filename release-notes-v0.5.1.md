# GharTV Jio Live v0.5.1 — TV test candidate

This is the first release intended for installation on the physical Hisense E6N.

## Included

- television-first phone-number and OTP connection;
- Jio live-channel guide, logos, search, categories and favourites;
- direct number tuning and Channel Up/Down;
- programme guide and Now/Next information;
- Media3 HLS/DASH playback and Widevine configuration;
- polished D-pad focus and full-screen player overlays;
- SHA-256-verified in-app update path.

## Excluded

No YouTube/free-web directory, provider launcher, M3U importer, repackaged JioTV APK, subscription bypass or DRM key is included.
