# Privacy

GharTV is designed for private household use.

## Data entered

- Jio mobile number;
- one-time password supplied by Jio.

The OTP is used for verification and is not stored. The mobile number and resulting session information remain on the television. Session material is encrypted through Android Keystore. The app stores the downloaded channel catalogue, favourites, last channel and last selected category locally.

## Data not collected by the developer

GharTV contains no advertising SDK, telemetry SDK, analytics service or developer-operated account server. It does not transmit the household's number, OTP, viewing history or session to Operon, GitHub or the developer.

## Network destinations

The application contacts Jio endpoints needed for authentication, catalogue, EPG and authorised playback, plus GitHub only when checking for a GharTV software update. Channel media may be delivered by broadcaster/CDN domains returned by Jio.

## Deletion

Use **Jio account → Sign out** to remove the encrypted Jio session and cached guide from the television. Android's **Clear data** or uninstall controls remove all remaining local GharTV data.
