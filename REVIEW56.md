# GharTV Review 56 — search-first film browser with Tor default

Review candidate only. Review55/54/53/52/51 remain rollback evidence. No public feed, merge, deployment or owner acceptance is implied.

Discover now opens one film-search toolbar above the original provider browser. The previous native suggestion surface and its Refresh/Open-provider/Privacy buttons are not part of the production flow. Submit a search and the toolbar hides, leaving the original page with the remote pointer. The Search key or Menu → Search films or series restores the toolbar; Menu also provides Back to TV guide, connection, route and local technical evidence.

The film browser prepares its app-local Tor route by default before the first provider navigation. The app-local route covers the film WebView, including public embedded player resources, so provider playback does not silently fall back to the failing direct route. Jio live TV, previews, updates, diagnostics, private/local hosts and lookalike top-level origins remain outside that proxy. Menu → FlixMomo route can return to direct, restart Tor or disable the default. Certificate verification, safe browsing, provider access checks, media gestures and DRM are unchanged.

Film error events include the event-time app version and direct/Tor route, never the query, title, URL, cookies or credentials. Recent technical errors display the latest bounded stage/code, local queue count and delivery status. An empty or queued local state is not collector acknowledgement.
