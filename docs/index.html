Already installed?

Open GharTV → Jio account → Check for GharTV update → Download update.

Allow GharTV to install updates if Android requests it, return to the app and check again, then confirm Install and reopen GharTV.

Do not uninstall or clear storage. Automatic checks are throttled to 12 hours; a manual check is the immediate route. The current app does not enforce mandatory or silent updates.

First installation

On Google TV, use a TV-compatible download/file-transfer tool to obtain the APK. For example, Downloader by AFTVnews can open amritsinghgit.github.io/ghartv.

Android may require permission for that tool to install unknown apps. Confirm installation, then disable the temporary permission for that tool again.

Open GharTV and connect your Jio mobile number using the OTP inside the app. Channels depend on that account's entitlements.

Remote-first controls

Arrows move focus. OK watches. Number keys tune directly. Channel Up/Down stays within the selected language, favourites or search view. GUIDE returns home; INFO/OK opens programme information.

The microphone invoking whole-TV search remains a known follow-up and was not made a blocker for this release.

Diagnostics stay optional

Choose Jio account → Diagnostics & privacy to enable, preview or turn off technical reporting. Missing diagnostics are not evidence of a healthy or unused TV.

The current release does not upload successful viewing history, precise location, Jio account data, OTPs, tokens or hardware identifiers.

This is an unofficial household client. It does not unlock subscriptions, bypass DRM or include a repackaged JioTV APK. Availability is controlled by Jio and channel providers. Package in.ghartv.nova · project lane ghartv · Source and continuity.
