Install on Google TV

  1. Install Downloader by AFTVnews from the TV Play Store.
  2. Enter amritsinghgit.github.io/ghartv.
  3. Choose the download button and allow Downloader to install unknown apps when Android asks.
  4. Install GharTV, then turn that permission off again.

First connection

  1. Open GharTV.
  2. Enter the 10-digit Jio mobile number.
  3. Enter the OTP received from Jio.
  4. The live guide opens and loads channels available to that account.

TV controls

Arrows move focus. OK watches. Number keys tune directly. CH ± switches channels. GUIDE returns home. INFO shows Now and Next.

Important

This is an unofficial household test client. It uses the connected account's entitlements and does not unlock subscriptions, bypass DRM or include a repackaged JioTV APK. Availability is controlled by Jio and channel providers.
