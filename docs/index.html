Clear expectations

Before you press play.

Does this page stream television?

No. GitHub Pages hosts this public website and download links. The web player requires the existing GharTV service and your own eligible provider session. Public or cousin-server streaming deployment is separate and is not established by downloading the app.

What does Tor cover?

Only the explicitly selected, isolated desktop Brave/Chromium provider session. GharTV detects an existing local Tor SOCKS service, verifies the route before provider access and does not fall back to direct. It does not provide all Tor Browser fingerprinting protections. Android and Jio playback do not automatically use that desktop route.

Will every FlixMomo result play?

Provider availability, browser framing, device support, region, login and entitlement rules still apply. A search result or loaded page is not playback verification. GharTV does not remove DRM, provider restrictions or subscription requirements. Use only content you are entitled to access.

Is picture stretching AI upscaling?

No. Fit, crop and stretch change presentation. GharTV does not claim to recover genuine detail with AI super-resolution.

Where does owner analytics data go?

The existing private owner service talks to the existing collector with a server-side credential. Reports are requested manually, with explicit freshness and error states. This public page does not expose viewing logs or owner credentials.
