Provider and network boundaries

FlixMomo has a separate Android entry from the guide and Jio login. It uses an in-app Chromium WebView. The Mac web companion has independent search and an explicit Browse FlixMomo action for the user to complete normal provider verification manually. It does not solve or bypass a CAPTCHA, login, entitlement or DRM restriction.

Optional desktop Tor routing uses installed Brave, Chromium or Chrome with an existing local Tor SOCKS service on 127.0.0.1:9050 or 9150. The browser checks the route before accessing the provider and does not fall back to direct. This is not full Tor Browser fingerprinting protection, and it does not route Android or Jio traffic. Direct embedded playback is disabled when Tor is selected.

GitHub Pages is the public download website, not a streaming backend. Public/cousin-server streaming deployment and AI super-resolution are not implemented by this delivery. The existing household photograph and birthday personalisation remain packaged; separate those assets before a general-purpose public edition.
