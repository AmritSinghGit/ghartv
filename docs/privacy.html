GharTV · v0.5.3

Privacy-first diagnostics

GharTV diagnostics are off until a person on the TV opts in. They exist to reveal technical failures on real Android TV and Google TV hardware.

Never sent

  • Jio mobile number or OTP
  • passwords, account IDs, tokens or cookies
  • stream, manifest or DRM licence URLs or request headers
  • successful channel names/IDs, programme titles or viewing history
  • IP address, Wi-Fi name, MAC, Android ID, advertising ID or TV serial number

Sent only after consent

  • GharTV version and random pseudonymous installation hash
  • TV manufacturer/model, Android version, locale and broad connection type
  • feature-use, guide/update result, startup and buffering measurements
  • scrubbed errors, short code stack frames, HTTP status, fingerprint and report reference
  • Jio channel ID only when that channel fails, so the failure can be reproduced

Control

Open Jio account → Diagnostics & privacy to turn diagnostics off, inspect queued reports, send now, or delete the queued reports and reset the diagnostic ID. Turning diagnostics off deletes unsent reports. Already accepted reports are not removed by this local action and expire automatically within 30 days.

Retention

Accepted events are retained for no more than 30 days. The app and collector independently remove sensitive fields. The collector does not intentionally read or store connection IP addresses.
