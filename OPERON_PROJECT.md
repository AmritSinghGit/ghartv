# Operon registration boundary

GharTV is registered in the existing Operon owner portfolio as an independent **project**, not as an Operon tenant and not as a VCNow capability.

## Canonical identities

- Portfolio/lane ID: `ghartv`
- Project: GharTV · Jio Live
- Package: `in.ghartv.nova`
- Local continuation path: `~/Downloads/GharTV_Nova_v0.4.2`
- Source repository after publication: `AmritSinghGit/ghartv`
- Owner portfolio registry: existing Operon Owner OS / portfolio work in Operon PR #39

## Authority split

- `AmritSinghGit/ghartv` is the source and release authority for the GharTV application.
- Operon records portfolio metadata, owner decisions, accepted/candidate versions and continuity receipts.
- Operon is not the source repository for GharTV and does not receive GharTV account data, OTPs, session tokens or channel payloads.

## Preservation rule

Continue the existing `ghartv` lane. Do not create a second GharTV lane, project ledger, database, branch family, product shell or worktree. Normal future releases use the same repository, package identity and signing key.
