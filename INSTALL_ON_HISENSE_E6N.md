# Install or update GharTV on the Hisense E6N

## Stable update after owner approval

1. Keep the existing GharTV installation; do not uninstall it.
2. Open **GharTV → Account → Check for GharTV update**.
3. Approve Android's in-place update prompt.
4. Confirm the encrypted Jio session, guide, favourites and diagnostics choice remain.
5. If Android asks for unknown-app permission, enable it only for the trusted downloader/GharTV installer, complete the update, then disable it again.

During RC2 review, installed televisions remain on stable v0.5.3. The stable v0.5.4 prompt appears only after the owner runs `GHARTV_PUBLISH_STABLE_V054.command publish` and the signed APK is verified.

## Fresh installation

On a trusted TV browser/downloader, open:

```text
https://amritsinghgit.github.io/ghartv/
```

Direct stable APK:

```text
https://github.com/AmritSinghGit/ghartv/releases/latest/download/GharTV-Jio-Live.apk
```

Install **GharTV · Jio Live**, then enter the Jio mobile number and OTP inside the app.

## Daily controls

- D-pad: move through home, guide or player actions.
- OK: watch; while playing, show the Now/Next panel.
- INFO: show/hide Now, progress and Next.
- Channel Up/Down: switch only within the exact view used to open playback.
- Number keys: tune from the complete Jio catalogue.
- GUIDE/TV/DVR: return to the guide.
- Hold OK on a guide card: add/remove Favourite.

A subscription or persistent Jio 403 cannot be bypassed. Use **Next working channel** to continue; GharTV keeps explicit Subscription and Needs attention views separate.
