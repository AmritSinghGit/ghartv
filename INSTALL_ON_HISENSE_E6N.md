# Install GharTV on the Hisense E6N

## Recommended TV method

1. On the Hisense Google TV, open the Play Store.
2. Install **Downloader by AFTVnews** or use another trusted TV browser/downloader.
3. Open Downloader and enter:

   ```text
   https://amritsinghgit.github.io/ghartv/
   ```

4. Select **Download latest GharTV APK**.
5. Android may ask permission for Downloader to install unknown apps. Enable it temporarily for Downloader.
6. Install **GharTV · Jio Live**.
7. Turn Downloader's unknown-app permission off again after installation.
8. Open GharTV from **Apps**.

Direct APK address:

```text
https://github.com/AmritSinghGit/ghartv/releases/latest/download/GharTV-Jio-Live.apk
```

Google search phrase after the public page has been indexed:

```text
AmritSinghGit GharTV Jio Live
```

Search indexing is not immediate; the exact installation-page address above is the deterministic route.

## First sign-in

1. Enter the 10-digit Jio mobile number.
2. Select **Send OTP**.
3. Enter the OTP received from Jio.
4. Select **Verify and open live TV**.
5. The guide opens immediately and loads the live catalogue.

The OTP is not stored. Session data is encrypted through Android Keystore.

## Daily remote controls

- D-pad: move through the guide.
- OK: open the focused channel.
- Number keys: tune by channel number.
- Channel Up/Down: switch channels.
- GUIDE/TV/DVR: return to the guide.
- INFO: show or hide programme information.
- Hold OK on a channel card: add/remove Favourite.

## Updating later

Open **Jio account → Check update**. GharTV verifies the published SHA-256 and then opens Android's installer. Android still requires explicit approval. Future builds must use the same GharTV signing key so they update this package in place.
